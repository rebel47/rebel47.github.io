# Mohammad Ayaz Alam - AI Engineer & Applied ML Developer Portfolio

Personal portfolio website showcasing production multi-agent systems, local LLM applications, enterprise NLP frameworks, and scalable machine learning pipelines.

Live website: [rebel47.github.io](https://rebel47.github.io)

## Design & Features

- **Modern Minimalist Aesthetic**: Crisp typography with Inter and JetBrains Mono, clean cards, subtle micro-borders, and high-contrast readability.
- **Recruiter-Focused Layout**: Immediate 5-second scanability featuring core qualifications, current roles, key metrics (90M+ records analyzed), and dual PDF downloads (`CV.pdf` and `Portfolio.pdf`).
- **Curated Flagship Projects**: In-depth architecture breakdown of Lattice Lab, Air Lune, Ilmora, Multi-Agent Project Generator, whenyouopen.me, Data Quality Assessment Tool, and Hugging Face RL model (3.6k+ downloads).
- **Searchable 25-Project Archive**: Instant client-side category filtering (AI & Multi-Agent, Applications, Data Science) and keyword search.
- **Open Work Experience Timeline**: Chronological, scannable career history across Zalion GmbH, Siemens Energy, Ilham Labs.ai, Institute for Employment Research (IAB), and BASF.
- **Light & Dark Themes**: High-performance theme toggle with system preference detection and localStorage persistence.
- **Zero Dependencies**: Pure HTML5, CSS3, and vanilla modern JavaScript. No build tools, bundlers, or frameworks required.

## Run Locally

Open `index.html` directly in any web browser, or serve locally with Python:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8000`.

## Repository Structure

- `index.html` - Clean semantic HTML5 markup, meta tags, and content.
- `style.css` - Custom design system, responsive grids, dark/light theme variables.
- `script.js` - Lightweight vanilla JS for themes, mobile navigation, clipboard copy, and project filtering.
- `assets/CV.pdf` - Downloadable Curriculum Vitae / Résumé.
- `assets/Portfolio.pdf` - Comprehensive 4-page Engineering Portfolio document.
- `assets/favicon.png` - Browser icon.
- `assets/social-preview.png` - Social sharing OpenGraph card.
- `image/` - Project screenshots and headshot assets.
