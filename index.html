Air Lune: Shared Flight Multiplayer Focus Space

A multiplayer focus space that turns deep work into a shared flight between real airports. Participants join a shared cabin, follow live deterministic aircraft movement across a MapLibre map, talk over low-latency LiveKit voice, and stay accountable with server-authoritative focus timers.

  • Deterministic Geospatial Movement: Renders flight progress from persisted schedules using PostGIS instead of streaming raw coordinates over WebSockets, minimizing latency & bandwidth.
  • Browser-to-LiveKit WebRTC Voice: Direct audio channels without API proxying, plus local audio engines for ambient cabin, rain, and white-noise soundscapes.
  • Server-Authoritative Focus Engine: Redis & FastAPI backend with local countdown reconciliation, persistent flight logbooks, and private task isolation.
  • Production Deployment: Containerized with Docker Compose and Caddy on AWS Lightsail, with retained Terraform ECS/RDS scaling paths.
